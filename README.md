## Learning Path

A practical progression through these **hands-on cybersecurity labs**:

1. Begin with **Guardrails in the Attic** and **Shadows in the Notes** for filesystem and Linux-security investigation.
2. Continue with **Thales Shift: Linux Perms** to strengthen Linux permission analysis.
3. Study **Cron Whisper** to understand security implications around scheduled tasks.
4. Explore **Backdoored Backup** and **Backup Script Breakout** to examine backup and automation security.
5. Move to **Tomcat Roleplay: Root** and **Tomcat Shadow Hunt** for web-server security practice.
6. Finish with **Shellshift: TTY Upgrade Lab** and **Fix the Shell, Own the Box** for shell and terminal-environment skills.
7. Use **Thales Shellcraft** as additional practice combining Linux and shell concepts.

Difficulty levels are not inferred unless explicitly provided by the supplied lab information.

## How to Use the Labs

1. Open a lab using the direct link in the collection.
2. Review the lab objectives and environment requirements.
3. Work only inside the provided CTF or authorized training environment.
4. Enumerate the environment methodically.
5. Record relevant permissions, files, processes, services, and configuration findings.
6. Analyze why a security weakness exists rather than only completing the challenge.
7. Where appropriate, document defensive controls and detection opportunities.
8. Keep all testing within systems you are explicitly authorized to assess.
